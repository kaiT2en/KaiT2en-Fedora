redistribute the code under those licenses. Nothing here narrows them.

The **name "KAIT2EN", the logo and the project's visual identity are separate
from the code licenses** and are not granted by them. They identify this
project and where its work comes from.

## What you may do

- Use and fork the code under its licenses.
- Refer to KAIT2EN factually: state that your work is based on, compatible
  with, or derived from KAIT2EN.

## What needs our permission

- Using the name "KAIT2EN" or the logo for a fork, distribution, product or
  service, or in a way that suggests it *is* KAIT2EN.
- Suggesting endorsement, affiliation or partnership with the KAIT2EN project.

A fork is welcome under the code licenses, but it must carry its own name and
must not present itself as KAIT2EN.

the Omarchy project or the Omacom Foundation.
