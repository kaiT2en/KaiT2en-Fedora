# What KAIT2EN stands for

KAIT2EN exists so that people can run a free operating system on their Apple T2
hardware, and it is built by a community that welcomes everyone regardless of
gender identity, sexuality, origin or background.

Discrimination against people for who they are runs against the reason this
project exists. The KAIT2EN name and brand will not be lent to, and will not
appear to endorse, projects or organizations whose public conduct is at odds
with that.

This is a statement of the project's values. The code stays free under its
licenses; how the KAIT2EN name may be used is described in TRADEMARK.md.
