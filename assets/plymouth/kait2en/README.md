# KaiT2en Plymouth theme

KaiT2en uses Plymouth's native `two-step` plugin. The plugin supplies the
password entry field, lock, password bullets, prompt, keyboard icon, active
keymap label, and progress bar. Plymouth provides the password prompt text,
including the encrypted device name and LUKS UUID.

`animation-0001.png` and `watermark.png` use the KaiT2en mark. The first is the
boot animation frame; the second keeps the mark visible while the password
dialog is displayed.

The password dialog assets (`entry.png`, `lock.png`, `bullet.png`,
`keyboard.png`, `capslock.png`, and `keymap-render.png`) are based on Fedora's
Spinner theme and are provided by the Plymouth project under GPL-2.0-or-later.
